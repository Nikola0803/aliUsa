# ALI USA

ALI USA is a standalone Next.js storefront spin-off built from the proven EVLV interface structure and restyled with a softer, spa-inspired visual system.

## Design direction

- Warm porcelain and blush surfaces
- Deep plum navigation and calls to action
- Muted rose accents
- Editorial serif display typography
- Rounded, image-led cards and restrained shadows

The direction is inspired by premium wellness and spa interfaces. It does not copy third-party branding, copy, or proprietary assets.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

Copy `.env.example` to `.env.local` and configure only the services this store should use. Analytics, CRM, live chat, inventory sync, and payment recipients intentionally have no inherited production fallbacks.

## Before launch

1. Supply the final ALI USA vector logo and brand contact details.
2. Connect a dedicated CRM brand/store record.
3. Configure inventory and payment recipients.
4. Replace inherited catalog photography or copy where licensing or positioning differs.
5. Complete legal, checkout, email, analytics, and mobile QA for the new business.
